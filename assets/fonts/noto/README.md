# Kanan supplier-form Indic fonts

These local WOFF2 subsets are used only inside the localized supplier application:

- Noto Sans Devanagari: Hindi and Marathi
- Noto Sans Gujarati: Gujarati
- Noto Sans Tamil: Tamil

They were generated from the Google Fonts variable sources on 5 September 2026. The subsets include the required Indic block, Latin text, common punctuation and the Indian rupee sign. The fonts are served locally; no external font service is used.
